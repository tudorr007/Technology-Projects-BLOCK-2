## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
It would cause problems on the network as the network wont know which device to send data to

### 5.2 Why do we use a switch instead of directly connecting PCs together?
make communication easier to manage and allows for all computers to communicate with each other

### 5.3 What does the subnet mask 255.255.255.0 indicate?
first three parts of IP address identifies the network, last part identifies the individual device, allowing up to 255 devices on the network
